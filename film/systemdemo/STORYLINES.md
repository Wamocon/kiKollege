# Systemdemo: drei Geschichten

Am 06.11.2026 vorgeschlagen. Der Projektverantwortliche hat am selben Tag die erste gewählt, dazu nachgebaute Oberflächen und nur die Stimme.

## 1. Ein Auftrag, einmal ganz durch (gewählt)

- **Mittel und Form:** Ein echtes Beispiel geht durch das ganze System, in einer Kette von Bildern, in der jedes Bild mit dem Ding endet, das das nächste öffnet.
- **Erste zwei Sekunden:** Ein Handy, in Telegram entsteht eine Nachricht an den Orchestrator.
- **Ablauf:** Nachricht → Hermes Agent legt Akte, Seele, Skills und Gedächtnis dazu → als Text an Qwen → der Zaun prüft den Aufruf → Karte auf dem Board, Fritz übernimmt → Fritz prüft das Quiz → der echte Befund „Integrationsrat statt Integrationsamt“ → unverändert zurück aufs Handy → „Ein Mensch entscheidet.“
- **Aussehen:** die Farben der Seite. Jede Station ist eine eigene Welt: weißes Telefon, dunkle Bühne für Hermes und Qwen, helles Board, Papier für das Quiz, rote Fläche am Schluss.
- **Ton:** die Erzählstimme, Thorsten, lokal mit Piper; keine Musik.

## 2. Die Werkstatt: WMC Inventar entsteht

- **Mittel und Form:** Eine Zahl landet; ein Bild baut sich immer weiter um.
- **Erste zwei Sekunden:** Die alte Excel-Liste kippt in ein leeres Raster aus 38 Kästchen.
- **Ablauf:** Gregor Dev füllt die Pakete → Theos Tests springen auf Grün → die Werkbank prüft im Browser → letzte Nachbesserung → bereit für die Abnahme durch einen Menschen.
- **Nicht gewählt**, unter anderem weil die Zahlen sich fast täglich ändern.

## 3. Der Zoom in den KI-Mitarbeiter

- **Mittel und Form:** Das Ding ist die Erklärung; ein Zoom ohne Ende.
- **Erste zwei Sekunden:** Werkbank und KI-Rechner von oben, die Kamera stürzt in den Rechner.
- **Ablauf:** Hermes → Profil → Akte → die Zeile „darf nie“ → der Zaun lehnt einen Aufruf ab → zurück zum Menschen.
- **Nicht gewählt**, weil kein Mensch mit einer Aufgabe darin vorkommt.
